# 日光留言墙

在线体验：[日光留言墙](https://stickywall.parva.cool/)，由 Parva 部署。

一面暖米纸纹的公共便利贴坐标墙。无需登录，访客可以自由选纸色、写字、画画，再亲手选择位置贴上墙。React + Vite + TypeScript 前端，Go + PostgreSQL 后端，可自行部署。

## 墙上的纸张

- 黄、绿、粉、蓝四色任选，不再分类。纸张宽 160–560、高 160–640；文字块自由定位，可拖动、键盘移动、调字号/墨色/宽度，也可绘制 SVG 涂鸦。
- 支持 Markdown 样式子集和编辑/预览切换。无固定行数，总文字最多 10000 个 Unicode 字符，最多 100 个文字块、300 笔和 30000 个点；可匿名或署名，署名最多 24 字。
- 首张中心放在原点半径 100 的圆内；普通纸张不重叠，与其它纸至少间隔 16，且与至少一张纸相距不超过双方宽高中最小值的一半。纸张逐步连接成一片。
- 先编辑，再放置。绿色斜线显示可建造区，红绿预览说明是否可贴；点击、拖动或方向键定位，最后确认保存。坐标永久保存，新留言和刷新不重排已有纸张。
- 选择当前浏览器自己的便签，可从其下半部叠一张新便签，不能完全盖住原纸；其余非祖先纸张仍至少间隔 16。还可附着不超过 3MB 的 PNG/JPEG 白边相片，相片可从原纸任意重叠位置附着，同样不能全盖原纸。
- 「我的便签」依赖 HttpOnly、SameSite=Strict 访客 cookie；清除 cookie 或换浏览器后不能继承归属，署名不用于认领。

## 浏览与恢复

拖动墙面或滚轮移动镜头，双指或 Ctrl/Command+滚轮缩放；左下角只显示缩放按钮和比例。镜头约束在便签边界外 1000 的范围内，并限制远离所有便签的空白区域。手机与电脑使用同一套坐标。右下角「贴一张」进入编辑器，桌面两栏、手机上下排列，下一步按钮固定可见。

每 15 秒读取新内容并合并，已有坐标不动。发布失败保留草稿；位置被并发占用时服务端返回 409，刷新墙面后可调整重试。草稿尽力保存在 localStorage，浏览器存储不可用或被清除时不保证恢复。服务端通过事务锁内校验避免并发位置冲突。

「无限墙」描述持续扩展的坐标空间。当前客户端仍逐页读取完整墙及图片，再只渲染视野附近的 DOM；网络、内存与整墙校验存在规模限制，不代表无限数据容量。布局、内容与图片保存在 PostgreSQL JSONB，旧记录只在没有 layout 时迁移一次，有坐标的纸不会被重排。旧分类与 6/9/12 行纸型 API 仅为兼容旧客户端保留，新版界面不再使用。

## 本地开发（Windows）

```powershell
# 首次准备 Go、PostgreSQL 到被 Git 忽略的 .local 目录
./scripts/setup-local.ps1
./scripts/dev.ps1
```

打开 [本地留言墙](http://127.0.0.1:5173)。

```powershell
# 停止前后端，保留数据库和留言
./scripts/dev.ps1 -Stop
# 可选：仅向空数据库手动导入示例
./scripts/seed-demo.ps1
```

## 自行部署

```powershell
Copy-Item .env.example .env
# 将 POSTGRES_PASSWORD 改为自己的 URL-safe 随机密码
docker compose up -d --build
```

默认访问 [本机 8080 端口](http://127.0.0.1:8080)，Go 同源提供前端和 API，PostgreSQL 使用持久数据卷。公网部署可配置 HTTPS 反向代理。环境变量、备份与检查见 [运行说明](docs/running.md)，接口与迁移见 [后端文档](server/README.md)。

## 项目结构

```text
web/             React 页面、样式、前端测试
server/          Go API、PostgreSQL 表结构与集成测试
scripts/         本地环境、启停与手动示例导入
compose.yaml     应用与 PostgreSQL 的部署配置
PRODUCT.md       已确认的产品约束
DESIGN.md        视觉规范与设计 token
```

本地演示留言均以「示例 · 」署名，正式部署不会自动生成留言。暖米纸纹、四纸色、宋体、胶带与柔影沿用既有品牌；纸纹来自 ambientCG Paper001（CC0），此轮未新增或替换位图素材。
